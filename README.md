# textutils-11
Group 11 - Python for Data Science Assignment 1

This project was created as part of the Python for Data course to practice Git collaboration and collective software development workflows. Together, we built and tested a small Python package that performs a variety of text-processing functions.

The unique_words function, implemented by Caroline, extracts all distinct words from a given text, converts them to lowercase, and returns them in alphabetical order for easier analysis.

The word_count function, developed by Francesco, calculates the total number of words in a text string, serving as a foundational metric for basic text analytics.

The is_anagram function, created by Brice and refined with input from Caroline, determines whether two strings are anagrams by comparing their character compositions after normalization.

The capitalize_text function, written by Francesco, ensures that each word in a given string begins with a capital letter, improving text presentation and readability.

The tokenize function, contributed collaboratively across the team, cleans and standardizes input text by converting all characters to lowercase and removing punctuation—returning a structured list of alphanumeric tokens.

The compare_texts function, implemented by Simon, measures the textual similarity between two inputs by comparing the overlap in their unique word sets.

The is_palindrome function, authored by Francesco, checks whether a sentence reads identically forwards and backwards, ignoring case and spaces.

Finally, the truncatestring function was developed jointly by all group members. It shortens a text string to a defined maximum length while maintaining readability by appending an ellipsis (...) when truncation occurs.
